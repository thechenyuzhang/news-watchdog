## TLDR

1. **Patch your Linux servers: CVE-2026-98432 (CVSS 9.8), and the remote-root exploit was written by an AI (Confirmed).** It's a use-after-free race in the IPv4 TCP stack that affects kernels from 4.4 on. Fixed kernels: **5.10.272, 5.15.223, 6.1.190, 6.6.159, 6.12.113, 6.18.56, 7.2.10 and 7.3-rc7**.
   - **Anthropic's Frontier Red Team says an unreleased Claude model wrote a zero-click remote-root exploit** against servers with an MPTCP listener. It leaked a kernel pointer in ~48 minutes and got a shell ~5 minutes later.
   - **Go 1.24+ turns MPTCP on by default for Linux listeners,** so ordinary Go services are exposed. Turning off MPTCP alone doesn't fix it. The interim workaround is an nftables rule that drops IPv4 TCP packets carrying IP options.
   - Distro status: Debian has shipped fixes. Ubuntu 22.04, 24.04, 26.04 and 26.10 still showed fixes in progress as of Oct 30. AlmaLinux kernels are in testing. Red Hat rates its exposure lower (5.9, mainly denial of service and hard to exploit).
   - No exploitation in the wild has been reported. HN 581.
   - ([Anthropic](https://www.anthropic.com/research/discovering-vulnerabilities-with-claude) · [BleepingComputer](https://www.bleepingcomputer.com/news/security/linux-kernel-exploit-enables-remote-root-attacks-on-mptcp-servers/) · [kernel CVE](https://lists.openwall.net/linux-cve-announce/2026/10/15/1) · [Red Hat](https://access.redhat.com/security/vulnerabilities/RHSB-2026-016) · [AlmaLinux](https://almalinux.org/blog/2026-10-30-cve-2026-98432/) · [write-up on HN](https://atlasum.net/blog/cve-2026-98432-linux-ipv4-tcp-uaf))

## What to read / what to watch

1. **Anthropic Frontier Red Team, "Discovering vulnerabilities with Claude"** (lab research, read with TLDR #1). It's the first public case of a model producing a **zero-click remote root on Linux** end to end. The practical lesson is the MPTCP exposure through Go's defaults and that the nftables workaround beats just disabling MPTCP. ([Anthropic](https://www.anthropic.com/research/discovering-vulnerabilities-with-claude))
2. **Nolan Lawson, "The AI cost of JavaScript frameworks"** (Oct 28, essay, **New creator**, HN 171). He had Opus 5.5 build the same app in 12 frameworks, 5 runs each.
   - Cost per run ranged from Hono+htmx at **$2.67** to Angular at **$4.97**.
   - Shipped JavaScript ranged from Astro at **0 KiB** to Next.js at **142 KiB**. Lines of code ran from 1,370 (Hono) to 2,009 (Angular). Lighthouse scores were maxed out everywhere, so they didn't separate anything.
   - SvelteKit cost more because agents read the v3 migration guide on every run. Agents often ignored the frameworks' own MCP servers and skills.
   - The takeaway: your stack choice now affects your inference bill. ([nolanlawson.com](https://nolanlawson.com/2026/10/28/the-ai-cost-of-javascript-frameworks/))
3. **Shijie Gan, "How I ship software with a team of AI agents"** (Oct 23, essay, **New creator**). A one-page design for a personal "software factory."
   - **Inputs:** asks arrive from Slack, GitHub and production alarms.
   - **Pipeline:** a dispatcher triages, then each task goes plan → tests first (written by a separate agent the builder can't touch) → build → proof enforced by a hook → fresh-context review → merge bot → staging, which rolls itself back if it breaks.
   - **Human gates:** he steps in only for big asks, production releases and changes to the agents' own rules.
   - **Numbers he reports:** 20+ tasks a day, ~1 hour median from task to merge.
   - **Sources:** it maps each decision to sources (OpenAI harness engineering, Anthropic, Stripe "minions," Spotify, Meta's Rule of Two, Lauren Tan's pstack).

   ([shijiegan.com](https://shijiegan.com/blog/how-i-ship-software-with-ai-agents))
4. **Latent Space, "Agents Prompt People: Using Agents for Long-Horizon Financial Work"** (Oct 31, podcast with Arca's Aman Singh). Covers deterministic safety rules, translating agent-written code into a strict query format before it touches data, and a "meta-agent" that improves the harness from advisor feedback and traces. ([Latent Space](https://latent.space/p/arca/))
5. **Andrej Karpathy, "HackerTube"** (Oct 31, HN 1631). A ~2-hour Claude Code build that turns HN comment threads into a video catalog (hackertube.org). Worth watching as a template for small, data-driven sites built in an afternoon. ([Karpathy](https://karpathy.bearblog.dev/hacker-tube/))
