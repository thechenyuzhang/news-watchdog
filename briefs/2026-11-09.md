## What to read / what to watch

**This week's theme:** keeping humans actually in charge of agent work — judgment, queues, and owners.

1. **Addy Osmani (Anthropic, Claude Code team), "Critical thinking when agents do the work"** (X essay, Nov 3; covered by Business Insider Nov 5, trending on X this weekend) — essay. **New creator** for these briefs.
   - Three levels of handing off thinking: offloading (fine, "I do this all day"), deferral (AI output becomes your input), and cognitive surrender (trusting it outright), which builds "cognitive debt."
   - His checklist: form a hypothesis before asking; ask the agent what it can and can't verify; know which skills you're no longer practicing. "When you can't explain the answer… you've ceded ownership."
   - Why now: lands the same weekend Goldman pulled agents from non-engineers.

   ([X thread mirror](https://threadnavigator.com/thread/2117512471930167377/) · [Business Insider](https://www.businessinsider.com/anthropic-engineer-addy-osmani-cognitive-surrender-warning-2026-11))

2. **Sergey Kuhne, "How I'm fighting the AI Brain Fry"** (Nov 8; HN 282) — short practitioner playbook. **New creator.**
   - Fix for juggling 20 agent tabs: every ticket is a markdown file in git; an agent works the board in cycles (research, build tickets tagged safe, test, browser-check, verify deploys) but never deploys to production.
   - Everything needing a human lands in one "owner inbox," rendered as a single Claude artifact rebuilt from git. Take one item, decide, close it back into the queue — "the context closes with it."

   ([sergeykuhne.com](https://sergeykuhne.com/blog/fighting-ai-brain-fry) · [HN](https://news.ycombinator.com/item?id=50416363))

3. **Latent Space × Mihail Eric (Stanford CS146S / Monaco), "How Stanford Teaches AI-Native Engineering"** (Nov 8, ~2-hour episode + write-up) — institutional Layer 1.
   - The course dropped exercises agents finish in one prompt; students now land real open-source contributions that maintainers review, so they must understand unfamiliar codebases and justify changes.
   - At Monaco, agents handle development and on-call investigation in internal agent workspaces that reproduce failures and test fixes; they buy tools like Devin for code review.

   ([Latent Space](https://latent.space/p/cs146s/))

4. **Y Combinator, "How To Build The Future: Paul Graham & Amjad Masad"** (Nov 7, 44 min) — institutional.
   - Replit's agent came from watching non-coders paste code and errors between ChatGPT and Replit, so it loops until the program works. PG's rule: make something 10% easier for consumers and you get twice the users.
   - Masad: one customer scoped a project at $10M and spent $250K on Replit ("outsourcing is sort of dead"); argues against flat per-employee token budgets because output varies 100×.

   ([YouTube via Followed](https://usefollowed.com/episodes/y-combinator-how-to-build-the-future-paul-graham-amjad-masad))

5. **Simon Willison, "Hide your slop PR descriptions behind `<details>`"** (Nov 9) — short post. Most of his changes now arrive as agent-opened PRs; agents write good PR descriptions but long ones, so tuck them away. ([simonwillison.net](https://simonwillison.net/))
