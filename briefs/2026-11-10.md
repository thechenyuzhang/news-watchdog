## What to read / what to watch

**This week's theme:** what changes when one model can run a thousand agents — and who notices when the work is bad.

1. **Ethan Mollick, "Fable 5.2 and Jagged AGI"** (One Useful Thing, Nov 9) — essay. Standing radar.
   - Tested Fable 5.2 as filmmaker, hardware hacker (turned a tiny USB keyboard into a six-game console with no docs), entrepreneur (screened 22 ideas, built "Prebid Brief" from 201 city/county agendas), literary scholar and social scientist. His verdict: "almost AGI."
   - The useful part is the failures: an accurate but joyless course, a 182-page paper because no critique ever cut anything, and a 25,000-agent project that wrote itself an 87,500-word rule book and slowed to a dozen worlds a day until he brought in "consultant" agents. His point: the model's own critics check facts, not whether the work is too long or no fun.
   ([oneusefulthing.org](https://www.oneusefulthing.org/p/fable-52-and-jagged-agi) · [Portals code](https://github.com/emollick/ai-portals))

2. **Carr Onstott & Mehul Jaiswal (Amazon), "Amazon saves millions by replacing Sonnet 4.6 with Strands Decider"** (Strands Agents blog, Nov 9; HN 486) — practitioner playbook. **New creator.**
   - A decision model returns a probability per option instead of text; they rewrote 20 label descriptions into one-sentence criteria to fit a 4,096-token window. 6,724 → 2,010 tokens per ticket, 4.2 s → 0.9 s, ~$0.0005 per ticket on one A10G.
   - Copy the rollout: an AppConfig switch with BEDROCK / DUAL / DECIDER modes, judging every disagreement on live traffic; rollback is a 45-second config change. Gotcha: JSON key order moved output probabilities by up to 0.19, so sort keys.
   ([strandsagents.com](https://strandsagents.com/blog/amazon-saves-millions-replacing-sonnet-with-strands-decider/) · [HN](https://news.ycombinator.com/item?id=50436640))

3. **Simon Willison, "Locating the source of a mysterious beep with Claude"** (Nov 9; HN 261) — build log. Standing radar.
   - Started on Claude Code mobile with Opus 5.5, then handed the running system to Fable 5.2; multiple phones/iPads become WebAudio listeners over WebSockets and triangulate a beep to ~40 cm (it was an old CO detector).
   - The reusable trick: a hot-swap `installModule()` path so the agent can push new code to every listener while it runs — "giving Claude Code ears."
   ([simonwillison.net](https://simonwillison.net/2026/Nov/9/mysterious-beeps/))

4. **Anthropic, Fable 5.2 & Mythos 5.2 System Card** — primary doc, skim sections 1.5 and 6.4. Why: AI-R&D capability limiting, sandbox-escape evals (3.1% vs 21% for Mythos 5.1), and the "model suspects it's being evaluated more often" caveat. ([PDF](https://assets.claude.com/27d60918d218125e7504bc7354c4b4626ec56b11.pdf))

5. **Google DeepMind, "Introducing AlphaProof Code"** — research post + paper. Humans and models write the spec; Gemini Carbon agents generate 6M+ lines of Lean; agents flag ~1% for human review; reintroduced old Signal bugs were caught as unprovable. Artifacts open-sourced. ([DeepMind](https://deepmind.google/blog/introducing-alphaproof-code/))
