## What to read / what to watch

**This weekend's theme:** how teams actually trust thousands of agent-written PRs.

1. **Lauren Tan, "All Code Is Slop (Except Mine)"** (AI Engineer talk, 17:32, Nov 14). *Standing radar.*
   - Describes an "inverted trust pyramid": deterministic layers (API design, architecture, lint, types, tests) at the base, then verification, then a thin layer of prose rules. Every agent correction becomes a deterministic check or an API change.
   - Dune ("Next.js for Electron apps") bans `useEffect` in product code, enforces the main/renderer import boundary with a dependency-graph analyzer, and bans ~99% of comments because agents use them to justify workarounds.
   - Verification replaces most review: Chrome DevTools-driven runtime checks, a user-facing **feature map**, TLA+ for cross-device notification flows, Lean proofs for a virtualization library, and Bombadil property-based UI tests. Most of her tokens now go to verification. Results: 11K PRs/month, ~0.5% reverts, a daily stable release, and an app that got *faster*. (PJFP notes that auto-merged fix-forwards make revert rate an imperfect quality metric.)
   ([YouTube](https://www.youtube.com/watch?v=O_zcc6Xl12g) · [AIE Talks summary](https://aietalks.com/talks/all-code-is-slop-except-mine))

2. **Alexander Marquardt, "Guardrails for coding agents: how a codebase stays sound at 1,600 merged PRs a month"** (Nov 8, long essay). **New creator.**
   - One e-commerce search repo merged **1,652 PRs in October** (median 492 lines), comparable to VS Code or CPython. 70% of the code is tests (3.4:1), all deterministic on recorded fixtures. CI runs **136 jobs**; 0.2–0.7% of merges are reverted.
   - Lists failure modes in plain language: tests that can't fail, tests that skip themselves, silent defaults, copy-paste, suppressed lint, agents deleting 110 files outside their task, guides so long they stop being read. Each now has a gate, and the gates are red-teamed with an "evasion kit" (10 of 12 planted evasions once got through).
   - The control plane is code: lane-weighted allocator, a 15-minute non-AI watchdog, "stop the line" on a red main. Tokens per changed line fell 3.3x. The open problem is rework (~1 fix round per PR).
   ([alexmarquardt.com](https://alexmarquardt.com/ai-tools/coding-agents-codebase-under-control/))

3. **Jackson Ly, "What broke when I ran 20 coding agents at 229B tokens a month"** (Nov 12, essay). **New creator.** Concrete failures: one agent ran 4.5 days on 40.8M tokens with zero commits; "CI green" covered 28 of 308 tests; a production outage happened while he slept. Fixes: a frontier model plans and reviews while cheap models (GLM/Grok/DeepSeek) execute, briefs written as contracts with failing acceptance tests first, small goals that can finish without a human, short rule files backed by hooks, and **no production merges overnight**. CI went from ~60 to <10 min per agent (~$120/mo). Keep your transcripts, because Claude Code deletes them after 30 days. ([jacksonly.xyz](https://jacksonly.xyz/blog/what-broke-running-20-coding-agents))

4. **Sebastian Raschka, "Understanding Positional Embeddings in Modern LLMs"** (Nov 15, technical tutorial). *2nd high-signal hit (first was the Oct 24 reasoning course), so he's promoted to the standing radar today.* Builds from GPT‑2 learned absolute embeddings and sinusoidal encodings to RoPE, with PyTorch code (split-half vs. interleaved pairing). Then a 2026 architecture census: full RoPE is still the default but declining; **partial RoPE** is now the majority among RoPE models (e.g., MiniMax-M3 rotates 64 of 128 dims); RoPE/NoPE hybrids are growing (SmolLM3 skips every 4th layer); Inkling uses a T5-style learned relative bias. His take: partial RoPE is "hardly worth it", and RoPE stays dominant into 2027. ([Ahead of AI](https://magazine.sebastianraschka.com/p/understanding-positional-embeddings))

5. **Operator_0x, "What thousands of conversations look like inside a language model"** (field notes, HN 45). **New creator.** Maps Qwen3‑1.7B residual-stream states for English, Chinese, German, Croatian and Python examples. Conversations show up as thin overlapping sheets; Latin-script languages and code share regions while Chinese sits offset. Exploratory work, and the author says PCA shows only part of the space. ([operator0x.com](https://operator0x.com/field-notes/qwen-conversation-state-space/))
