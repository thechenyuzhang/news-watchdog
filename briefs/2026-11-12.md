## What to read / what to watch

**This week's theme:** what the engineer's job becomes when agents write and check the code.

1. **Swami Sivasubramanian (AWS), "AWS Emulator and the engineer's job when agents write the code"** (guest post on Werner Vogels' All Things Distributed, Nov 11) — essay plus build story. **New creator for this list.**
   - Starts with Amazon's Paxos lock service "Alf," which was tested by simulating its whole environment in one JVM, and asks whether agents can build those test environments for 200+ services themselves.
   - The recipe: agents write **fidelity tests** from AWS's public Smithy API models, fix each test until it passes against *real* AWS, then build the emulator until it passes the same test. Every change passes a **merge gate** that includes several adversarial security agents. Swami's own lesson: he watched Kiro fail for four nights on rebuilding Alf's replication engine until he gave it a spec and a test environment, and then it took about two hours.
   ([All Things Distributed](https://www.allthingsdistributed.com/2026/11/aws-emulator-and-the-engineers-job-when-agents-write-the-code.html) · [GitHub](https://github.com/aws/aws-emulator))

2. **a16z (Olivia Moore & Justine Moore), "Welcome to the B2A Economy"** (Nov 10) — institutional thesis, first in a series.
   - Claim: agents are now most web traffic. Data points: agentic-browser traffic grew 8x Aug→Oct (Human Security; Muse ~60%, OpenAI ~30%), Shopify AI-driven traffic 8x and orders ~13x, 40%+ of GitHub PRs start with an agent draft, Vercel agent-triggered deploys 28x.
   - Four categories to build in: agents/agentic models, products newly made possible by agents, incumbents optimizing for agents (GEO extended into buying), and agent infrastructure (payments, fraud, identity, communications). Read it next to United's ban.
   ([a16z](https://a16z.com/welcome-to-the-b2a-economy/))
