## What to read / what to watch

**Today's theme:** a report is a claim, not proof. Agent output, Lean proofs and app backends all need an independent check.

1. **Christopher Weir, "Coordinating coding agents in a large codebase"** (Nov 2026, essay + Claude Code skill). **New creator.** About 90 Claude Code worker sessions produced 60+ merged PRs in ~5 weeks, coordinated by one "ringleader" thread he messaged ~200 times (~15 words each). Rules: split work where file ownership is clear; put blocking decisions in the brief, because "you cannot talk to a busy worker" (one waited ~10 minutes and then proceeded on its own); "a worker's report is a claim, not proof", so the ringleader rereads the diff, reruns checks and exercises the user flow (which caught a double-submit bug after hundreds of tests had passed). Operational lesson: four parallel workers filled the disk in an hour, so briefs now set a free-space floor. ([christopher-weir.com](https://christopher-weir.com/2026/11/coordinating-coding-agents-in-a-large-codebase))

2. **Xena Project (Kevin Buzzard's Lean blog), "…and the proof is checked in Lean"** (Nov 12, essay; HN 123). **New creator.** Four questions to ask before trusting an AI-generated Lean proof: does the Lean statement match the paper; does it compile (Anthropic's 13M-line FLT proof needed a 96-core, 500 GB machine); does it prove the stated theorem without hidden redefinitions or axioms (`lake comparator`); and does it survive independent kernels (`--paranoid`). Of OpenAI's 290 papers that came with Lean code, ~38 don't state the main theorem in Lean at all. Useful template for any "verified by machine" claim. ([xenaproject](https://xenaproject.wordpress.com/2026/11/12/and-the-proof-is-checked-in-lean/))

3. **Steve Blank, "What's Next for Nvidia?"** (Nov 15, essay; HN 363 / 458 comments). *2nd high-signal hit, so he's promoted to the standing radar today.* Argues visionary CEOs are usually replaced by execution CEOs (Gates→Ballmer, Jobs→Cook) and that it shows when the market shifts. Huang reinvented Nvidia three times (CUDA 2006, deep learning 2012, Mellanox/racks 2020), ran ~60 direct reports and said he didn't believe in succession planning. The bets an execution CEO trims first are the ~$50B in lab investments and the yearly chip cadence. "Execution pays your salary, innovation pays your pension." ([steveblank.com](https://steveblank.com/2026/11/15/whats-next-for-nvidia/))

4. **Marc Pope, "24,664 Lovable apps serve database rows to anyone, and Supabase's fix skips tables already open"** (Nov 15, analysis). **New creator.** Explains why the leak happens: tables created by SQL or agents (not the dashboard) historically got RLS off plus anon grants. Supabase's breaking change (default for all projects since Oct 30) protects only *new* tables. Lovable's publish scan warns, but only new Enterprise workspaces block publishing on critical findings by default. Includes a two-line curl self-test and the RLS policy fix. ([marcpope.com](https://www.marcpope.com/blog/24-664-lovable-apps-serve-database-rows-to-anyone-and-supabase-s-fix-skips-tables-already-open))

5. **Nick Boariu, "Day 2 with Coding Agents: The Discipline of Operating and Refactoring Live Production Code"** (Nov 4, essay; first time in our briefs). **New creator.** A PM running a live app agent-first for 10 months: replaced a rotting "memory bank" with single-owner reference docs and deletable task files; set a three-tier blast radius where agents can never deploy auth or payments to prod without a human `--confirm-critical` flag; used a read-only adversarial audit agent that caught a Supabase RLS bug that had hidden a banner for all 1,400 users; and enforced App Store rules with bundle scanners, not prompts. ([nickboariu.io](https://nickboariu.io/post/day-two-coding-agents-production-discipline/))

6. **OpenAI's new science blog: Nathaniel Craig, "A step toward defining the Standard Model on a lattice"** (Nov 15, guest essay). A UCSB physicist says GPT‑6 Astra "took the lead in developing the detailed proof" of a candidate nonperturbative lattice definition (fixing the chiral-fermion phase problem that has been open for 25+ years), with outside lattice experts reviewing it. He calls it a beginning, "far more an answer in principle than in practice". Read it next to item 2. ([OpenAI](https://openai.com/index/step-toward-defining-the-standard-model))
